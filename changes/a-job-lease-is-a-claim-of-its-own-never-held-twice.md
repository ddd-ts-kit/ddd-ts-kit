**A run left behind no longer writes into the run that took its job: the lease of a background job is a claim of its own, never held twice.** A lease was `{ id, attempt }`, and the attempt number comes back: `release` gives it back and `retryDead` starts it again. A job that ignored its signal when its worker stopped went on behind with the very lease of the next claim, so its late `saveCheckpoint` or `reportProgress` was accepted and the next attempt resumed from a stale checkpoint. Every store now counts the claims of a job apart from its attempts and never gives one back, and `JobLease` is that fence, a value object the store mints at each claim (`JobLease.ofClaim(id, claim)`) and hands with the job (`ClaimedJob.lease`): `InMemoryJobStore`, `KnexJobStore`, `DrizzleJobStore`, `PrismaJobStore`, `TypeOrmJobStore` and `RedisJobStore` alike. `ClaimedJob.attempt` still says which attempt the run is. `jobStoreContract` gains two cases, a job released and a job revived are claimed under a new lease and the run of before is not heard, and asks of every claim the lease it hands (#900).

To move: the table of the background jobs gains a column, `claims`, an integer that is not null and defaults to 0. Write the migration before the new version runs, `alter table <schema>.background_jobs add column claims integer not null default 0`: by hand on Knex (`createJobTable` writes it for a new table only), generated from the table of the package on Drizzle and TypeORM, and on Prisma after adding `claims Int @default(0)` under `attempts` in the `BackgroundJob` model, as `prisma/jobs-and-processes.postgresql.prisma` shows it. Workers of the version before keep running over the migrated table, and Redis needs nothing. Code that wrote a lease by hand (`{ id: job.id, attempt: job.attempt }`) passes `job.lease`, the one the claim handed; a spec builds one with `JobLease.ofClaim('job-1', 1)`. A `JobStore` of your own counts the claims of a job at each `claim`, never moves that count back, hands `lease: JobLease.ofClaim(id, claims)` with each `ClaimedJob`, and holds its reports to `lease.claim` where it held them to `lease.attempt`: run `jobStoreContract` on it.
