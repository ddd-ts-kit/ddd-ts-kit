**`ddd-ts-kit check` reads what it used to miss: a changed file whose name git quotes.** `check --changed-since <ref>` and `verify-slice --since <ref>` dropped the findings of a file with a non-ASCII character in its name (`café.vo.ts`), because git printed the path quoted: a gate on the changed files passed a file it should have refused. The three commands that ask git what changed (`check --changed-since`, `mutation --changed`, the files of a worker and of a story) now read it through one function, which takes each name as it is on disk and counts a renamed file under both its names. `mutation --changed <ref>` counts from where the branch left `<ref>`, as `check --changed-since` does, so the files the trunk changed meanwhile are no longer listed.
