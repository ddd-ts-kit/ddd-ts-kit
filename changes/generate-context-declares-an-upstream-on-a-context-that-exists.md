**`generate context` declares an `--upstream` on a context that exists.** Run on a context already in the config, it kept the context as it was and recorded nothing, so a relationship found after `init --context` had to be written into `ddd-ts-kit.config.json` by hand. It now adds each `--upstream` the context does not declare yet to `contexts.<name>.upstreams` and redraws the `CONTEXT.md` of both sides, and refuses one that already depends on the context, naming the chain (`context/no-cycle`).
