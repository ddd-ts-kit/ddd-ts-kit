**The guard asks about a suppression in a source, a test or a script only.** A document that names `eslint-disable`, `@ts-ignore`, `it.skip` or `as any`, such as a decision record or the constitution of Spec Kit that forbids them, suppresses nothing: the guard no longer puts it to the project owner, which in `claude -p` refused the write. Adding one to a `.ts`, `.js` or `.mjs` file or to a `.vue`, `.svelte` or `.astro` component, is asked about as before.
