**A generated project is formatted by Biome 2.6.8.** `init` pins `@biomejs/biome` 2.6.8, the version the kit and the example run, and the `$schema` of the `biome.json` it writes names it.

To move: nothing is required, a project that stays on 2.6.6 keeps working; to follow, `npm i -D -E @biomejs/biome@2.6.8` and set the `$schema` of `biome.json` to `https://biomejs.dev/schemas/2.6.8/schema.json`, then `npm run format`.
