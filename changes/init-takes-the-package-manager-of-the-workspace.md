**`init` takes the package manager of the workspace a project is a package of.** Run in a package of an npm workspace (an Nx workspace, `packages/api`), it chose pnpm, its default, and wrote a project the repository does not install. Without `--package-manager`, a new project now reads the nearest folder above it that declares a workspace (`workspaces` in its `package.json`, or a `pnpm-workspace.yaml`): the `packageManager` it pins, else its `pnpm-workspace.yaml` or lockfile, else npm. A note says where it was read. Outside a workspace, or in a workspace of a manager the kit does not write for (yarn, bun), the default is unchanged.
